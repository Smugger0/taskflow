TaskFlow

A priority-based task scheduler with a graphical interface and a command-line interface.
Runs on Windows, macOS, and Linux — no installation required.

v1.0 Python 3.6+
stdlib only

📋Overview

TaskFlow lets you manage tasks at three priority levels — High, Medium, and Low. The built-in priority queue always surfaces your most urgent work first. You can also create recurring tasks that automatically reschedule themselves after being completed.

⚡

Priority Queue

High-priority tasks always appear at the top, powered by a Min-Heap.

🔁

Recurring Tasks

Set a repeat interval (days) and the next occurrence is added automatically.

🔍

Search & Filter

Find tasks instantly by keyword or narrow the list by priority level.

💾

Auto-persistence

Tasks are saved to tasks.json and reloaded on the next run.

▶️Running the App

Graphical Interface (recommended)

python gui.py

Opens the full tkinter window with toolbar, task list, and search bar.

Command-Line Interface

python main.py

Text-based menu driven interface. Both share the same tasks.json save file.

Tip: Both interfaces read and write the same tasks.json file, so you can switch between GUI and CLI freely.

🔧Toolbar

The toolbar is split into two rows to keep all controls visible at any window size.

Row 1 — Actions

  • ＋

  • ↻

  • ✓

  • ✏

  • 🗑

  • 📊

  • 💾

  • ❓

Row 2 — Search & Filter

  • 🔍
    Search bar — Live keyword filter; the list updates on every keystroke. Click × to clear.
  • ⬇
    Priority dropdown — Filter the list to show only High, Medium, or Low priority tasks.

＋Adding Tasks

One-time task

  1. Click ＋ Add Task in the toolbar.

  2. Enter a Title (required) and an optional Description.

  3. Choose a Priority: High, Medium, or Low.

  4. Optionally enter a Due date in YYYY-MM-DD format.

  5. Click Add (or press Enter) to confirm.

Recurring task

  1. Click ↻ Add Recurring in the toolbar.

  2. Fill in Title, Description, and Priority as above.

  3. Set Repeat every (days) — the interval between occurrences, e.g. 7 for weekly.

  4. Click Add to confirm. After you complete this task, the next occurrence is queued automatically.

Note: The Title field is required. All other fields are optional — description defaults to "(no description)" and priority defaults to Medium.

✓Completing Tasks

To mark a pending task as complete:

  • ✓
    Select a row and click ✓ Complete in the toolbar.
Tip: Double-clicking a row opens the Edit dialog, not the Complete action. Use the ✓ Complete button in the toolbar to mark a task as done.

Both methods show a confirmation dialog. After confirming:

  • 📁
    One-time task: Moved to the Completed tab.
  • 🔁
    Recurring task: Moved to Completed and a new occurrence is added to Pending with its due date set N days from today.

🔍Search & Filter

Keyword search

Type in the Search box in the toolbar. The pending task list updates instantly as you type. The search is case-insensitive and matches against both the title and the description.

Clear the search box to show all pending tasks again.

Priority filter

Use the Priority dropdown next to the search box. Select High, Medium, or Low to show only tasks at that level. Select All to remove the filter.

Tip: Search and priority filter work together — you can search for "meeting" while filtering on "High" to see only high-priority meeting tasks.

📂History Tab

Click the Completed tab (next to Pending Tasks) to view all tasks that have been marked as done. The most recently completed task appears at the top.

Completed tasks are read-only — they cannot be re-opened or deleted from the GUI. The history is preserved across sessions.

📊Statistics

Click 📊 Stats in the toolbar to open a summary dialog showing:

  • 📋
    Total number of pending tasks
  • ✅
    Total number of completed tasks
  • 🔴
    Pending tasks broken down by High / Medium / Low priority

💾Saving & Loading

Tasks are saved to tasks.json in the same folder as the scripts. The file is created automatically the first time you save.

  • 🚪
    On exit: A dialog asks whether to save before closing. If you choose Yes, tasks are saved silently without an extra popup.
  • 💾
    Manual save: Click 💾 Save in the toolbar (or press Ctrl+S). A “Tasks saved successfully” confirmation popup appears.
  • 📂
    On startup: Tasks from the previous session are loaded automatically.
Warning: If you close the window and choose No in the save dialog, any unsaved changes since the last save will be lost.

🎯Priority Levels

Every task has one of three priority levels. The queue always presents higher-priority tasks first.

LevelRow colourWhen to use
High Light red Urgent — deadlines, blockers, critical items
Medium Light yellow Important but not immediately urgent
Low Light green Nice-to-have, background tasks

📝Task Types

Task (one-time)

A standard task. Once completed it moves to history and does not reappear. Use this for anything that only needs to happen once.

Recurring Task

A task with a repeat interval in days. When completed:

  1. The completed instance is moved to history.

  2. A new instance is automatically created with the due date set to today + interval.

  3. The new instance gets its own unique ID and appears immediately in the Pending list.

Examples: weekly review (7 days), daily standup (1 day), monthly report (30 days).

❓FAQ

Where is my data stored?

In tasks.json inside the same folder as gui.py / main.py. You can back it up, copy it, or delete it to start fresh.

Can I edit a task after creating it?

Yes — select the task in the Pending list and click ✏ Edit in the toolbar (or press Ctrl+E). A pre-filled dialog lets you update the title, description, priority, and due date. Only pending tasks can be edited; completed tasks in the History tab are read-only.

What happens if I delete tasks.json?

TaskFlow will start with an empty task list on the next run. No error is shown — a missing file is treated as a first run.

Can I run GUI and CLI at the same time?

It is possible but not recommended. Both processes write to the same tasks.json and there is no file-locking, so changes from one will overwrite the other on the next save.

The GUI window looks small. Can I resize it?

Yes — the window is freely resizable. The minimum size is 640 × 420 px.

🧪Running Tests

TaskFlow ships with an optional pytest test suite (tests.py) that verifies the core business logic without launching the GUI or the CLI. All tests are self-contained and leave no files behind.

Prerequisites

Install pytest once (no other dependencies required):

pip install pytest

Running the full suite

From the project folder:

pytest tests.py -v

You should see 39 tests collected and all marked PASSED. Expected output:

======= test session starts =======
...
39 passed in 0.10s

Running a single test class

Stopping on first failure

pytest tests.py -x
